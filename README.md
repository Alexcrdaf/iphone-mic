# iPhone 14 Pro → Windows Microphone Bridge

Использование микрофона **iPhone 14 Pro** как отдельного основного микрофона на **Windows 11/10** через локальную сеть (Wi-Fi / Ethernet) с выводом в виртуальный кабель **VB-Audio Virtual Cable**.

- Веб-клиент для iPhone: [`https://alexcrdaf.github.io/iphone-mic/`](https://alexcrdaf.github.io/iphone-mic/)
- На ПК работает локальный HTTPS/WSS-сервер (`server/app.py`) и панель управления с QR-кодом (`http://127.0.0.1:8780`).

## Быстрая установка на Windows

1. Установите **VB-Audio Virtual Cable** с официального сайта [`vb-audio.com/Cable/`](https://vb-audio.com/Cable/) (распаковать ZIP → `VBCABLE_Setup_x64.exe` от имени администратора → **Install Driver** → перезагрузить ПК).
2. После перезагрузки верните свои обычные наушники устройством воспроизведения по умолчанию, а `CABLE Output` в разделе **Запись** переименуйте в **`Микрофон iPhone 14 Pro`** и сделайте микрофоном по умолчанию.
3. Откройте правило брандмауэра для порта `8443` (можно через `scripts/setup-windows.ps1` от имени администратора).
4. Установите зависимости и запустите сервер:
   ```powershell
   pip install -r requirements.txt
   python -m server.app
   ```
   Или просто двойным кликом запустите `Run_iPhone_Mic.bat`.
5. Отсканируйте QR-код камерой iPhone 14 Pro.

## Про режимы «Изоляция голоса» и «Широкий спектр» на iPhone 14 Pro

- В интерфейсе страницы можно переключаться между **«Изоляция голоса»** (голосовой профиль с шумоподавлением/эхоподавлением), **«Широкий спектр»** (чистый необработанный звук 48 кГц) и **«Свой профиль»**.
- Аппаратные режимы Apple в iOS переключаются системно: пока микрофон активен (горит оранжевый индикатор сверху), смахните **Пункт управления** справа сверху → нажмите **«Режим микрофона»** → выберите **Изоляция голоса** или **Широкий спектр**.
